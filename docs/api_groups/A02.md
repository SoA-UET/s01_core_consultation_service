# A02 Group

This is the group of APIs between
the [S01 - Consultation Service](../services/core/S01_Consultation_Service.md)
and [S02 - Consultant AI Agent](../services/core/S02_Consultant_AI_Agent.md)

This API consists of 1 API(s).

## A02

This API is based on RabbitMQ.

This API is offered by S02 and is used/called by S01.
Direction: S01 → S02

S01 must send requests to the queue `telcenter_ai_agent_requests`
and get responses from `telcenter_ai_agent_responses`,
asynchronously.

The queue names must be configurable via environment variables:

- Request queue: `TELCENTER_AI_AGENT_REQUESTS_QUEUE`
- Response queue: `TELCENTER_AI_AGENT_RESPONSES_QUEUE`

The API has 1 method.

### A02 Method: `handle_inquiry`

Request body format:

```json
{
    "method": "handle_inquiry",
    "params": {
        "inquiry": "Gói cước này giá bao nhiêu vậy?",
        "history": "User: Xin chào\nAgent: Xin chào quý khách..."
    },
    "id": "unique-request-id"
}
```

Response body format: receive multiple streaming responses on the response queue:

**Success (streaming tokens):** there would be
multiple messages like the following. S01
must concatenate the contents to form
the full message. Additionally, it must
yield the contents as they arrive to
the frontend immediately.

```json
{
    "id": "unique-request-id",
    "result": {
        "status": "success",
        "content": "Dạ, ",
        "seq": 0
    }
}
```

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the `content` should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.

A special error is when the content being `FORWARD`.
In this case, the AI agent cannot answer the question
factually; S01 should forward the conversation to a
human consultant. For example:

**Error:**
```json
{
    "id": "unique-request-id",
    "result": {
        "status": "error",
        "content": "FORWARD",
        "seq": 0
    }
}
```

Additionally, if the content is empty,
it means the streaming has ended.

The sequence number `seq` starts from 0
and increments by 1 for each token.
This guarantees the order of the tokens,
and also helps the caller to detect any missing tokens
and wait for them if necessary.
